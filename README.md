# 游戏大厅 🎮

几个纯 HTML/CSS/JS 写的小游戏，无需安装、打开即玩。

在线体验：<https://yandi-y.github.io/games/>

## 游戏列表

| 游戏 | 文件 | 说明 |
|------|------|------|
| 扫雷 🚩 | `minesweeper.html` | 经典扫雷 · 无猜模式 · 逐步提示 · 三难度最快记录 |
| 日月棋 ☀️🌙 | `riyueqi.html` | 翻转石砖，点亮所有太阳 · 随机/自定义 |
| 2048 🔢 | `game2048.html` | 经典数字合成 · 合并相同数字，挑战 2048 |

## 本地运行

直接双击任意 `.html` 文件，或打开 `index.html` 进入游戏大厅即可。

## 结构

- `index.html` —— 游戏大厅导航页
- 每个游戏一个独立的 `.html` 文件，互相独立、无依赖
